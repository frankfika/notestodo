## 1. 嗓音选型

### 1.1 候选对照（同一句 = VO-01「开会的时候，你是在参与讨论，还是在忙着抄笔记？」）

`f0_med` = 基频中位数，`f0_IQR` = 基频四分位距（**越小越稳、越克制**，越大越"演"）。

### 1.2 为什么选 Shelley (Chinese (China mainland))

1. **音区最低**：f0 中位数 170 Hz，是四个中文女声候选里最低的（Tingting/Meijia 228 Hz、Sinji 200 Hz）。
   低音区天然更"沉稳"，配合 `--text-1 #3A3128` 这种暖墨色纸感视觉，气质对得上。
2. **起伏最克制**：f0 四分位距 64.9 Hz，比 Tingting（83.1）、Meijia（80.7）**小约 22%**。
   分镜要的是"不卖弄"的纪录片旁白，而不是情绪起伏大的广告口播。
3. **稳定**：同一句在不同 rate 下重跑，时长与 f0 统计量重复性好（见 `_scratch/rate/results.json`），
   没有出现吞字、爆音或半句截断；Shelley 是这几种嗓音里唯一在长句（VO-04/VO-06）上也没有"赶"感的。
4. **普通话（China mainland）**：产品是国内语境、文案含「一言结论 / 行动项 / 收件箱」这类大陆用词，
   zh_TW（Meijia）/ zh_HK（Sinji）会在个别字上带口音，不适合。
5. **速率可塑性好**：从 rate 130 到 220 有单调且线性的时长响应（不像 Tingting/Meijia 在 130–145 区间"卡住"不变），
   所以能逐句微调以贴合分镜时长。

**统一使用同一嗓音 Shelley**，只在 rate 上逐句微调（见下表），不做多嗓音拼接 —— 单支旁白的音色一致性优先。

### 2.1 关于 vo-08 / vo-09 超长（需要 Lead 决定）

这两条**不是语速没调好，是文案字数与分镜段长的矛盾**，实测数据如下：

| ID | 有效字数 | 段长 | 需要的速率 | 我的取值 | 结果 |
|---|---|---|---|---|---|
| vo-08 | 61 字 | 7 s（SH-08 位于 74–85 s） | ≈ 7.4 字/秒 | rate 180 → 5.1 字/秒 | 12.699 s，**超段 3.20 s** |
| vo-09 | 41 字 | 7 s | ≈ 8.3 字/秒 | rate 180 → 5.2 字/秒 | 7.941 s，**超段 0.94 s** |

- 中文纪录片旁白的自然语速约 **4.5–5.5 字/秒**；要压进 7 s，vo-08 需要跑到 rate 320 以上、vo-09 需要 250 左右，
  实测那种速度已经**吞字、听不清**，且与前后句子音色节奏完全脱节，所以我**没有**那么做。
- 我选了"**保旁白自然度、把超长如实交出来**"：两条都用 rate 180（已是舒适上限）。
- 三个可选处理（**均由 Lead 决定，我不擅自改分镜**）：
  1. 把 SH-08 段长 11 s → **15 s**、SH-09 段长 7 s → **9 s**，总片长仍可控制在 90 s ± 3 s 内（需重新配平 10 个段的伸缩）；
  2. 接受 vo-08/vo-09 的话尾**跨段**，用 0.5 s crossfade 吃掉一部分（画面先走、声音后收）；
  3. 若必须严格 90 s，可对 vo-08 的 `[[slnc]]` 之间做 6–8% 的加速（`ffmpeg -af atempo=1.06`，仍在自然范围内，可再省约 0.7 s）。
- 我倾向方案 1（改动最小、听感最稳）。

## 3. 断句与拼接说明

本次 **10 条全部一次 `say` 成句，没有做"拆两次 say 再拼接"**。原因：

- vo-03 / vo-04 / vo-06 原先担心偏长（分镜要求 13/14/14 s），实测 rate 145 / 155 / 160 就分别落在
  11.79 s / 12.24 s / 11.67 s，**一次成句的时长已经在段内**，且 `say` 自身在「。」「；」「：」处的自然停顿
  位置正确（用 `silencedetect` 抽查，停顿落在分句处，见第 4 节）。
- 拆句拼接反而会在接缝处引入电平/基频跳变（两次独立合成的人声相位不连续），听感上比"稍快但连续"更差，所以没用。
- 若后续文案再加长导致超段，建议的拼接方式（留档备查）：
  ```bash
  # 分两次合成相同嗓音/相同 rate，再在分句标点处拼接（不额外加 crossfade，避免相位抵消）
  say -v "Shelley (Chinese (China mainland))" -r 155 -o a.aiff "<前半句。>"
  say -v "Shelley (Chinese (China mainland))" -r 155 -o b.aiff "<后半句。>"
  ffmpeg -v error -y -i a.aiff -ar 48000 -ac 1 a.wav
  ffmpeg -v error -y -i b.aiff -ar 48000 -ac 1 b.wav
  ffmpeg -v error -y -i a.wav -i b.wav \
    -filter_complex "[0:a]adelay=150|150,apad=pad_dur=0.150[x];[x][1:a]concat=n=2:v=0:a=1" \
    -ar 48000 -ac 1 -c:a pcm_s16le vo-XX.wav
  ```
