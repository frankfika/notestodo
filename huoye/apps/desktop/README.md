# 活页桌面端

这是一个最小的本机窗口，用来打开已经在跑的活页网页。它不是把整个应用重写成原生程序，也不打包安装包、不做自动更新。

## 怎么运行

先启动网页和 API，再打开窗口：

```bash
pnpm dev
pnpm desktop
```

也可以在这个目录里运行 `pnpm start`。窗口标题是「活页」，默认加载 `http://127.0.0.1:5173`。如果本机服务还没起来，窗口会说明请先运行 `pnpm dev`。

指定端口（例如打开 5174 上的另一套本机实例）：

```bash
HUOYE_WEB_PORT=5174 pnpm desktop
```

桌面壳只连接 `127.0.0.1` / `localhost` 上配置的网页端口，不会打开远程网站。密钥仍然只保存在工作区的 `secrets.json` 里，与网页版相同。

在「设置 → 连接器」里，桌面窗口会多一个「浏览…」按钮，调用系统文件夹对话框。选定的路径仍要经过本机 API 校验：家目录、空路径或 `~` 不会被添加。没有桌面壳时，网页版可以粘贴完整路径，效果相同。

桌面 preload 运行在 Electron 沙箱里，只能引用 `electron`，不能再 `require` 本地模块，否则桥接失败，这个按钮就不会出现。
