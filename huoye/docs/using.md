# 日常使用

这一页说的是：文件放在哪、什么事会先问你、定时任务怎么跑，以及健康、录音、通道和本地文件夹现在实际能做什么。

## 记忆在哪

活页把关于你的记录写在工作区的 `memory/` 里，默认是 `~/Huoye/memory`，也可以用 `HUOYE_HOME` 换目录。基本档案在 `about-you/`，日记在 `diaries/`，健康手记在 `health/`，录音纪要在 `recordings/`。用普通编辑器打开这些 markdown 即可。

页面里看到的是整理过的正文；文件里还会留下出处一类的元数据，保存时会保留，不会在界面上逐条念出来。

导出在「设置 → 导出」，会打成一份压缩包，里面带着记忆文件。没有付费墙，也不需要先配模型密钥。

## 先确认，再行动

改 `about-you/` 里的核心档案、对外发消息，活页会先给出确认卡。你可以改预览再批准，也可以不用。没批准就不会写出去。

从不可信的地方听来的话，只会先记到日记或附件里，并标明出处，不会直接写进基本档案。

## 今天、简报和定时任务

打开「今天」就能看简报、未完成的任务、当天的健康和录音入口。没有模型密钥时，点「再整理一版」会按本地档案直接整理，并在页面上说明这一点。配好密钥后，会请模型来写；如果模型没写出来，会诚实告诉你原因，并改用本地档案，而不会假装那是模型写的。

定时任务由本机 API 进程里的调度器触发，不必另起一个守护进程。`pnpm dev` 起来后大约每 10 秒看一次，启动时也会先补看一轮。服务器关掉期间错过的到期时间，恢复后只会补跑最近这一次；每天重复的任务不会把错过的每一档都补上。任务跑完会把结果记到当天日记。

简报还有自己的早上 08:00、晚上 21:00 锚点。设置里的主动性如果不是「关闭」，到点（或服务器晚到、当天这一份还没有）也会自动整理一版并保存。本地整理不会记假的 token 用量。

## 健康手记和录音

健康页可以记下睡眠、活动、心情和备注，写在当天的 `memory/health/日期.md` 里。今天的首页健康卡片只概括最新的一笔。

录音可以在页面里录，也可以上传音频。音频文件放在 `data/recordings/`，不进记忆仓库的 git。纪要写在 `memory/recordings/`。没有配置转写接口时，录音仍会保存，只是不会假装已经转写成文。

可穿戴设备目前只是占位，状态是未连接，这一版不会从手环或手表拉数据。

## 本地文件夹

「设置 → 连接器」里可以添加一个或多个你指定的文件夹。路径会写在工作区的 `data/local-folders.json` 里，不会进仓库。

添加必须是你的明确操作：在页面里粘贴完整路径后点「添加文件夹」，或在桌面窗口里用「浏览…」打开系统对话框再选定。不会自动扫描 `$HOME`、`/home` 或整块磁盘。空路径、单独的 `~`，以及家目录、`/home`、磁盘根目录都会被拒绝。

只有已经添加、并且现在存在、可读的文件夹才会显示为「已连接」。目录不存在或没有读取权限时，会显示明确错误，而不会假装已连接。添加后可以查看这个文件夹的顶层内容；不会在添加时偷偷扫完整棵目录树，不会跟随指向所选文件夹以外的符号链接，也不会把文件上传到云端。聊天和每日简报目前还不会自动引用这些文件夹。

要移除时，在对应路径旁点「移除」即可。

## 通道

设置 → 通道里有飞书、Lark、钉钉、微信。它们走官方开放平台的协议，不是个人号协议。

必填凭证没配齐时，状态就是「未连接」。这是正常的。要在真实环境里收发，需要你自己在对应开放平台创建应用，并把一个公网可访问的地址指到本机的回调路径。本机默认只听 `127.0.0.1`，所以通常还要自己做一层映射。具体字段、路径和本机模拟器见 [channels.md](channels.md)。

就算通道已经连上，对外发消息仍然会先走确认卡。通道没连上就批准，也只会记下「没有发出去」，不会偷偷调用发送接口。

## 模型密钥

密钥只写在工作区的 `secrets.json`（权限 0600）里。请到「设置 → 模型」添加 MiniMax（国内或国际）或其他 OpenAI 兼容接口。不要把密钥粘进仓库、`.env` 或命令行环境；运行时也不会从这些地方读取密钥。
