# 活页 · 视觉规范（空气里的一页今天）

一句话：**活页像空气里的一页今天——头顶一片冷雾，脚下一点暖沙，卡片浮在光里，话从胶囊里说出来。**

参考 Today 的光与层次、Muse 的留白与「少放东西」，但所有色值、形状、图形与文案都自绘自配：
不搬运任何第三方品牌的图形、图标、角色或营销素材，也不去对齐任何官方色值。

> 本篇是活页自己的规范。方向来源见 `/workspace/todayai-research/VISUAL-DIRECTION.md`，
> 布局决策见 `/workspace/todayai-research/TODAY-LAYOUT.md`；两份只作参考，落地的写法以本篇为准。

---

## 1. 氛围洗底

整个底是一层竖向的、很淡的氛围渐变，不是任何一块实色：

| 位置 | 色值 | 感觉 |
| --- | --- | --- |
| 顶部 | `#eef2f6` | 冷雾 |
| 中段 | `#eef1f4` | 干净的过渡，不带色 |
| 底部 | `#f6efe7` | 暖沙 |

```css
body {
  background: linear-gradient(180deg, var(--hy-bg) 0%, #eef1f4 45%, var(--hy-bg-warm) 100%);
  background-attachment: fixed;
}
```

规则：

- 上冷下暖，中间干净过渡；不铺第二层底色，不做「贴一张纸在桌面上」的效果。
- 洗底是唯一的底。页面里不再有满屏的色块，也不做暗色模式的对立面。
- 禁止紫粉霓虹、彩虹色块、饱和色底、发光边框、纯黑纯白硬边。

## 2. 玻璃卡

卡片是浮在洗底上的一片半透明浅白，不是画在屏幕上的框：

```css
--hy-surface:   rgba(255, 255, 255, 0.72);  /* 玻璃卡面 */
--hy-surface-2: rgba(255, 255, 255, 0.55);  /* 次级面：内嵌块、列表行 */
--hy-surface-3: rgba(255, 255, 255, 0.86);  /* 更实的白：助理气泡、输入框底 */
--hy-line:      rgba(255, 255, 255, 0.62);  /* 卡片边线：很淡的白 */
--hy-radius:    18px;                       /* 玻璃卡圆角 16–20px */
--hy-blur:      saturate(1.12) blur(14px);
--hy-shadow:    0 1px 2px rgba(36, 50, 72, 0.05), 0 8px 24px rgba(36, 50, 72, 0.05);
```

规则：

- 玻璃面 = 白 70–80% + 轻微模糊；模糊只用来柔化背后的洗底，不做毛玻璃特效表演。
- 圆角 16–20px（当前 18px），控件圆角 12px，胶囊 999px。
- 阴影极轻且偏冷灰，两层：一层几乎看不见的接触阴影，一层散开的柔影。
- 边线用很淡的白，不用深色发丝框；控件（输入框、按钮）例外，用冷灰边 `--hy-line-2: rgba(27, 38, 58, 0.10)`。

## 3. 字体

界面与正文一律无衬线；衬线只留给笔记编辑器的长文正文。

| 用途 | 家族 |
| --- | --- |
| 拉丁 / 界面 / 正文 / 标题 | Figtree Variable（`@fontsource-variable/figtree`，SIL OFL） |
| 中文 | Noto Sans SC Variable（`@fontsource-variable/noto-sans-sc`，SIL OFL，随包发布） |
| 笔记编辑器长文正文（唯一例外） | Source Serif 4（中文回落 Noto Serif CJK SC / Songti SC） |
| 数字 / 路径 / 标识 / 时间戳 | Geist Mono |

字族栈（`packages/ui/src/styles.css` 的 `--hy-font-sans`）：

```css
--hy-font-sans: "Figtree Variable", "Figtree", "Noto Sans SC Variable", "Noto Sans SC",
  "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
```

规则：

- **中文先排好。** 中文必须用随包发布的 Noto Sans SC，不要靠系统回落：系统 PingFang / Noto Sans CJK SC 与拉丁的 x-height、字重都对不上，混排会又硬又散。
- **中文标题、问候、日期、说明一律 `letter-spacing: 0`**（最多 +0.01em）。禁止负字距，禁止把 0.08em 这类西文小标签字距套到中文日期上。眉题用字号、字重、灰阶分层，不靠拉开字距。
- 标题、问候、区块标题都用无衬线（`--hy-font-sans`），不靠衬线撑气质。
- 字重：正文 400，行高 1.65–1.75；区块标题与导航 500；600 只留给真正的第一级标题（页面标题、笔记标题），而且**不再同时收字距**。
- 问候语：38px / 字重 500 / 行高 1.3 / 字距 0。不要 600 + 负字距，中文会挤成一团、发堵。
- 一套正文的家族不超过两个；同一屏里不要同时出现衬线正文和无衬线正文。
- 问候可以很大（`--hy-fs-display`），但大不等于衬线。
- 衬线字重只用 400 / 600，且只出现在笔记编辑器长文正文（`.hy-note-body`）；笔记标题、卡片标题一律无衬线。
- 窄屏输入框字号不小于 16px（移动端浏览器会自行放大更小的输入框，放大后输入胶囊会压到底栏之上）。
- 等宽（Geist Mono）只给时间戳、路径、标识，不要用在问候和正文。

## 4. 字号梯度

| token | 值 | 用途 |
| --- | --- | --- |
| `--hy-fs-xs` | 12px | 时间戳、角标、脚注 |
| `--hy-fs-sm` | 13px | 次要说明、表格行 |
| `--hy-fs-base` | 15px | 正文 |
| `--hy-fs-md` | 16px | 强调正文、列表主行 |
| `--hy-fs-lg` | 19px | 区块标题 |
| `--hy-fs-xl` | 24px | 页面副标题 |
| `--hy-fs-2xl` | 30px | 页面主标题 |
| `--hy-fs-display` | 38px | 今天页问候语 |

行高 token：`--hy-lh-body: 1.7`（正文）、`--hy-lh-title: 1.35`（标题）。

对比原则：问候语与正文之间靠字号拉开，不靠字体家族；区块标题与区块正文之间靠字号 + 灰阶区分，不靠颜色。

字号梯度只有这一套，不要临时拍 32/22/14；要加一级就先改 token，再改文档。

## 5. 间距

4 的倍数，基础 `--hy-s1: 4px` … `--hy-s10: 64px`。

页面级间距走三个 token（定义在 `packages/ui/src/styles.css` 的 `:root`，
窄屏用 `@media (max-width: 899px)` 覆盖）：

| token | 桌面 | 窄屏 | 用途 |
| --- | --- | --- | --- |
| `--hy-page-x` | 32px | 20px | 页面左右留白：顶栏、主内容、窄屏底栏、窄屏输入胶囊共用同一个值 |
| `--hy-block-gap` | 32px | 24px | 区块之间：问候组 / 今日安排 / 简报卡 / 痕迹 |
| `--hy-card-pad` | 24px | 24px | 玻璃卡内边距 |

规则：

- **全页只有一套左右边距。** 顶栏的 padding、`.hy-shell-main` 的水平 padding、
  窄屏底栏的 `left/right`、窄屏输入胶囊的 `left/right` 全部读同一个 `--hy-page-x`，
  不允许某一处再写死 12 / 16 / 22 / 24。
- 窄屏把 `--hy-page-x` 收到 20px，但**顶栏、主内容、输入胶囊、底栏仍然是同一个值**：
  屏幕窄不改变「品牌 / 问候 / 内容右缘 / 底栏」落在同一条竖线这件事。
- 区块间距只用 `--hy-block-gap`，不手写 20 / 28 / 30。相邻区块的外边距会合并，
  所以「简报卡 → 痕迹」之间就是一个 `--hy-block-gap`。
- 玻璃卡内边距统一 `--hy-card-pad`（24px），卡内不再各写 20 / 22。
- 宽屏两栏之间：左栏内容右缘与分割线之间留 16px，分割线与右栏内容之间留 40px；
  内容不贴线。左栏左缘保持 0 内边距，贴着页面边距，才能和顶栏品牌对齐。
- 宽屏右栏的输入胶囊左右不额外缩进，正好落在对话列的两条竖线上
  （气泡左缘 / 页面右缘），和气泡、内容同一条节奏。
- 正文列宽 ≤ 680px（今天页），设置页正文列宽 ≤ 760px。

## 6. 墨色与强调色

```
--hy-ink        #1b2230   正文与标题
--hy-ink-soft   #4b5567   次级正文
--hy-ink-faint  #79839a   说明、时间戳
--hy-accent     #2f6fb0   强调：沉静的蓝（活页自配）
--hy-accent-hover #255a92
--hy-accent-soft rgba(47, 111, 176, 0.12)
--hy-warm       #b5763f   暖色：极少量点缀（今日标记、引文符号）
--hy-danger     #b04a3a
```

- 强调色是活页自己配的沉静蓝，不取任何官方品牌蓝的色值去「对齐」。
- 暖色只做点缀，占比很小；不用它当主色。
- 层级靠字号、字重、留白与玻璃面的浓淡，不靠颜色数量。

## 7. 导航

- 窄屏：屏幕底部一条悬浮胶囊 Tab，选中项略深（半透明白底 + 深一点的墨色），不是网站式下划线，也不是实心蓝块。
- 宽屏：安静的顶部导航，左右结构保留（品牌在左、主导航居中/靠右、设置在右）。
- 激活态只用半透明白 + 更深的墨色表示，不靠实心色块抢层级。

## 8. 输入

- 输入是悬浮胶囊（`border-radius: 999px`），浮在内容之上，不贴死底边、不加顶部分割大条。
- 窄屏时胶囊必须完整露在底部导航栏之上（底栏高度 `--hy-mobile-nav-h: 52px`，再加安全区与间隙）。
- 胶囊自身是更实的白面（`--hy-surface-3`）+ 冷灰边，聚焦时边框转为强调色。

## 9. 对话

- 用户气泡略灰（半透明白偏冷），助理气泡更白（`--hy-surface-3`），都用圆角气泡。
- 助理回答里的笔记/任务卡只保留标题 + 一句说明，点进去再看全文；不要把完整字段表铺在气泡里。
- 卡片标题用无衬线 500（`.hy-chat-card-title`、`.hy-chat-preview-title`），气泡里不出现衬线。
- 对话区本身不加边框，靠留白与气泡的浓淡分层。

## 10. 简报

- 一块玻璃卡，3–4 条短句要点；不铺成加框的长文清单。
- 主行动只有一个实心胶囊（例如「查看全文」），其余降级为文字按钮。

## 11. 痕迹

- 健康、录音、会议这类痕迹收在左栏底部一行轻链里，不与主内容平起平坐，也不跟悬浮输入抢位置。

## 12. 按钮层级

| 层级 | 形态 | 用法 |
| --- | --- | --- |
| Primary | 强调蓝实底、白字、胶囊 | 每屏最多一个主行动（生成简报、发送） |
| Secondary | 玻璃底 + 淡冷灰边、胶囊 | 并列的次要行动（新建、取消、返回） |
| Tertiary | 无框文字按钮 | 导航式跳转（打开记录、去新建任务） |
| Danger | 白底 + 红字红边、胶囊 | 删除、移除 |

规则：**一屏只允许一个实心主色**；其余降级为玻璃底或文字按钮。实心色块是稀缺资源。

## 13. 动效

- 只对 `opacity / transform / border-color / background-color / box-shadow` 做过渡，160–220ms，`cubic-bezier(0.2, 0.6, 0.2, 1)`。
- 禁止 `transition: all`；禁止发光、缩放弹跳等夸张动效。
- 悬停只让玻璃面「白一点 / 线深一点」，不飞起、不发光。

## 14. 「少」的原则

- 打开就要知道下一步：左边看今天，右边说话。
- 敢留白；工具浮出来，屏幕上少放东西。
- 不堆第三列，不把完整简报长文和完整字段表同时铺开。
- 每屏一个主行动，一套正文字体不超过两个家族，一层底色。

## 15. 明确禁止

- 不搬 Today / Muse 的品牌图形、图标、角色形象或营销文案。
- 不抄任何官方色值来「对齐品牌」；所有色值自配。
- 不做紫粉霓虹、发光边框、彩虹色块、饱和色底、纯黑纯白硬边。
- 不做网站式下划线导航、不做实心色块导航。
- 不写 `transition: all`，不做发光与弹跳动效。
- 不用无限画布或自由拖拽卡片墙来组织「今天」。

## 16. 页面调性速查

- **今天**：左右分栏。左栏是短问候 + 今日安排 + 简报要点 + 痕迹轻链；右栏是对话与悬浮输入胶囊。
- **聊天**：气泡对话。用户气泡略灰、助理气泡白；附带卡只留标题 + 一句说明。
- **任务 / 记忆**：安静的条目列表，靠很淡的冷灰线分隔，状态用文字 + 半透明小标签。
- **设置**：左侧安静的文字索引（细左线表示位置），右侧内容按区块分隔。
- **引导**：一块居中的玻璃卡 + 一个主按钮 + 一个文字次按钮。
